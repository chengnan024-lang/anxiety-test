# 雪人 · 手书

一部用代码一笔一笔"画"出来的手书（手書き MV），配《雪人》。

> 雪人就是"我"。他站在"你"家门前，从初雪等到春天。
> 14 幕：初雪 → 冷 → 窗 → 等 → 一片一片 → 心疼 → 缤纷 → 春天要来了 → 回忆 → 门前 → 梦 → 高潮 → 融 → 尾声。
> 完整分镜见 [STORYBOARD.md](STORYBOARD.md)。

所有画面都是实时画出来的：线条每一帧都会轻轻抖一下（手书的"沸腾线"），动画按 12 帧/秒走，像一张张手绘稿连起来放。

## 怎么看

1. 用 Chrome / Edge 打开 `index.html`（双击就行；需要联网加载手写字体）。
2. 点「选择《雪人》音乐文件」，选你电脑 / 手机里的那首歌。
   - 电脑上也可以直接把 mp3 拖进页面。
   - 或者把 mp3 改名成 `song.mp3` 放在 `index.html` 旁边，打开页面会自动载入。
3. 不选音乐也能看：点「先不放音乐，直接看」，默认按 4 分 30 秒播放。

音乐只在你自己的浏览器里播放，不会上传到任何地方。

## 歌词

导入一个 `.lrc` 歌词文件（「歌词」按钮，或者拖进页面；也可以命名成 `lyrics.lrc` 放在旁边）。
歌词会用手写字一个字一个字写出来。导入歌词后，前奏 / 间奏 / 尾声会自动按歌词的空白段对齐。

> 本项目不附带歌词，歌词版权归原作者。

## 对拍（让画面卡准你的版本）

每个版本的《雪人》长度、段落不一样，默认时间轴只是按比例分配的。想卡准：

1. 点「对拍打点」，从头播放；
2. 听到该换下一幕的时候按 **K**（手机上点「打点」）。14 幕，一遍按 13 下；
3. 按错了按 **U** 撤销，**[** / **]** 把当前这一幕的起点前后挪 0.1 秒（加 Shift 是 1 秒）。

打点会自动存在浏览器里。「导出时间轴」会下载 `snowman-timeline.json`，换电脑时「导入时间轴」就能恢复。
按 **B** 跟着拍子敲 4 下以上，部分画面会跟着节拍轻轻跳。

## 导出视频

- **浏览器录制（最简单）**：电脑上用 Chrome / Edge，先用按钮选好音乐，再点「录制视频」（或按 **R**）。
  它会从头完整播一遍并录下来，播完自动下载 mp4 / webm。录的时候别切走这个标签页。
- **逐帧导出（画质最好）**：装了 Node.js 和 ffmpeg 的话：

  ```bash
  npm i -D playwright && npx playwright install chromium
  node tools/render.mjs --audio 雪人.mp3 --lrc 雪人.lrc --timeline snowman-timeline.json --out 雪人手书.mp4
  ```

## 快捷键

| 键 | 作用 |
|---|---|
| 空格 | 播放 / 暂停 |
| ← → | 快退 / 快进 5 秒（Shift：1 秒） |
| ↑ ↓ | 上一幕 / 下一幕 |
| K / U / [ ] | 打点 / 撤销 / 微调 |
| E | 导出时间轴 |
| B | 敲拍子 |
| R | 录制视频 |
| F / H / ? | 全屏 / 隐藏界面 / 帮助 |

## 自己改

每一幕都是 `scenes/` 里的一个文件，改起来不会影响别的幕。接口说明在 [SCENES.md](SCENES.md)，
角色（雪人、红手套、窗、门……）在 `js/characters.js`，场景顺序和默认时长在 `js/timeline.js`。

截图检查某一幕：`node tools/snap.mjs touch --p 0,0.25,0.5,0.75,1`
